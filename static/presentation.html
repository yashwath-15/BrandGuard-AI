07System Architecture

Layered design: backend owns keys, rules and decisions

🖥️

Presentation Layer

React, TypeScript, Tailwind CSS — brand setup, submission, audit report, review and approval screens.

⚙️

API & Application Layer

REST API with Pydantic validation, authentication and role-based permissions.

🔍

Audit Services

Document processing · Deterministic rule engine · Brand retrieval (RAG) · OCR & visual checks · Finding validation · LLM analysis service.

🗄️

Data Layer

SQLite (MVP) — guidelines, approved facts, content revisions, audit reports, review decisions, audit logs.

External AI Service: Gemini API or a replaceable LLM provider, called only by the backend. API keys stay on the backend. The LLM never sets permissions or approvals.

🔍 Pipeline Components

  • 📄 Document retrieval (RAG) — Finds guideline and fact passages that apply
  • 🧠 LLM analysis — Tone, messaging, explanations and rewrites
  • 👁️ OCR — Extracts text from images for the same checks
  • 📊 Structured output — Replies must match a schema and cite evidence

❓ Why Combine Rules + AI?

  • ⚙️ Rules catch what must never vary: terms, facts, disclaimers
  • 🧠 The LLM handles nuance: tone and rewrites
  • ✅ Findings are validated before they are shown
  • ⚠️ Missing evidence is labelled "unverified", never "false"

Uses retrieval and prompting over brand documents. Does not include training a proprietary model.

11Security & Responsible AI

Designed for confidential brand material and human control

🔐 Protecting Data & Access

  • 🔑 API keys stored on the backend only
  • 🔒 Authentication and role-based access
  • 🏢 Workspace-level data isolation
  • 📁 File validation and upload restrictions
  • 🛡️ Confidential brand documents handled per workspace
  • 🗑️ Data minimisation and retention controls (planned)

🤖 Responsible AI

  • 🛡️ Prompt-injection protection: uploaded text treated as data, never as instructions
  • 📢 Disclosure of external AI processing to users
  • ⚠️ Uncertainty labels and source-backed explanations
  • 👤 Human oversight: no automatic publication
  • ✅ Reviewers keep final approval for high-risk or uncertain content

⚠️ Missing evidence is not proof that a claim is false. It is labelled "Unverified" for a human to review. BrandGuard AI does not promise complete security or guaranteed legal compliance.
